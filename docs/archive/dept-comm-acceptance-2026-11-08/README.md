## 二、怎么用

1. 直接打开 `reports/` 下的 Markdown 即可阅读，图片从 `../evidence/e2e-shots/` 相对引用，离线可用。
2. 需要核对某张图是否被改动，查 `MANIFEST.md` 第一节的 SHA256，或执行：
   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath .\evidence\e2e-shots\dept-comm\01-manager-待办详情.png
   ```
3. 需要比对原始版本，看 `reports-original/`。

## 三、归档时做了什么（三件，均不改变结论）

1. **图片本地化**：36 处图引用全部改为包内相对路径，逐张校验字节一致。图片不另存副本，直接引用 `evidence/e2e-shots/`，避免同一证据出现两份。
2. **通用报告图注纠偏**：原报告第 4–11 张图相对图注整体偏移一位，原因是「步骤 3 发起成功」与「步骤 4 主待办锁定」同屏、脚本只产出一张截图。归档版按画面内容重新对齐，步骤 3、4 共用 `03-manager-已锁定.png`。共 8 处纠偏，明细见 MANIFEST 第三节。
3. **补入配套文档**：把汇总验收单、上线检查清单、岗位组配人核对表、流程对照表、账号清单一起收入 `reports/`，避免验收结论与实施依据分散。

法务、财务两份报告的 24 处图引用与原图逐张一致，未作任何调整。
