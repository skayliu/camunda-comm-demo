## 三、遗留风险分级

| 级别 | 风险项 | 影响 | 建议动作 | 责任方 |
|---|---|---|---|---|
| **高** | 真实组织岗位组未配人（`legal_*`、`finance_*`、`dept_*_clerk`） | 节点停在无人认领，流程永久挂起且无告警 | 上线前逐组核对成员数与兜底人；增加"节点无人可认领"告警 | 实施/运维 |
| **高** | 通用流程文书解析为 `<deptId>_clerk` 组第一人，组空时回退部门第一人 | 部门意见可能落到无权限或不相关的人 | 生产强制配置文书组，关闭回退分支 | 开发 |
| **中** | 仅验证 H2，7 种方言脚本未实测 | 生产库可能的 DDL/方言差异 | 按实际库执行一次 V5 脚本并回归 | 实施 |
| **中** | 后端 81 用例本轮未重跑 | 后端状态以历史记录为准，非本轮证据 | 发版前跑一次 `mvn test` 全量 | 开发 |
| **中** | 一人多岗依赖演示数据（frank 3 岗、henry 3 岗） | 真实组织三岗分三人时脚本直接失败 | 改 4 个环境变量与 `NODES` 数组映射 | 测试 |
| **低** | 脚本写入真实数据（各 1 条主流程 + 1 条子流程） | 生产库会被污染 | 仅对演示库执行，或加数据清理 | 测试 |
| **低** | 同账号二次登录互踢，返回 401 | UI 与 API 不能同时用同一账号 | 已在脚本内分时序处理，无需改产品 | — |
| **低** | 截图直链签名约 1 天有效 | 报告图片过期不可见 | 归档 `e2e-shots` 三目录 | 测试 |
| **低** | 仅无头模式执行，未跑 `SMOKE_HEADED=1` | 视觉细节未经人眼确认 | 上线前人工点一遍关键页 | 产品 |

## 四、放行建议

**功能维度：可进入下一阶段。** 三条流程的"发起 → 锁定 → 部门内闭环 → 回填 → 解锁"主链路已在真实浏览器中闭合，接口、引擎状态、界面态三者一致。

**上线前必须先关闭的两项高风险**：岗位组配人与文书组兜底逻辑。这两项都不是代码缺陷，而是**组织数据配置**问题，测试环境用演示账号跑通不代表真实组织能跑通。
